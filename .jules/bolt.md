## 2024-05-24 - Lifting State up and Memoization in Central React Layouts
**Learning:** In a central React layout component like `MainLayout`, lifting state up (e.g., tracking `CodeEditor` keystrokes via `code` state) causes the entire layout and all its sibling components to re-render on every state change (e.g. keystroke). If heavy sibling components are present (like a file explorer or chat panel), this leads to severe layout thrashing and unnecessary reconciliation, significantly bottlenecking frontend performance.
**Action:** When tracking frequent state changes in a parent layout, explicitly memoize heavy sibling components using `React.memo` and ensure that all callbacks passed as props to them are wrapped in `useCallback` to prevent unnecessary component tree updates.
