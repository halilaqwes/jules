## $(date +%Y-%m-%d) - [React Layout Thrashing Prevention via Memoization]
**Learning:** In the frontend React app, when lifting state up to a central layout component (like `MainLayout` tracking `CodeEditor` keystrokes), heavy sibling components (`AgentSidebar`, `FileExplorer`, `ChatPanel`) must be memoized using `React.memo` to prevent severe layout thrashing and unnecessary reconciliation on every keystroke. Additionally, any callbacks passed down must be wrapped in `useCallback` to maintain referential equality and ensure `React.memo` actually works.
**Action:** Always wrap heavy, static, or isolated UI panels with `React.memo` and strictly use `useCallback` for their event handlers when rendering them alongside components with high-frequency state updates (like code editors or real-time logs).
