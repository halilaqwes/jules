## 2023-10-27 - [Prevent Layout Thrashing on Keystroke via State Lifting]
**Learning:** When a root layout component (like `MainLayout`) controls active editing state (e.g., Monaco editor contents via keystrokes) by lifting state up, every single keystroke triggers a full reconciliation of the entire layout tree. In this architecture, this forces heavy sibling components (`FileExplorer`, `ChatPanel`, `AgentSidebar`, `CodeEditor`) to re-render synchronously with the keystrokes, creating severe layout thrashing and input latency.
**Action:** Always memoize heavy sibling UI components (`React.memo`) and their event handler props (`useCallback`) when their parent container dynamically tracks high-frequency state like text input. This completely stops the downward re-render cascade into unchanged layout panels.
