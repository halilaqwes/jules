## 2024-05-16 - Optimizing MainLayout Re-renders in React
**Learning:** In the React frontend, lifting the `code` state up to `MainLayout` to power the `CodeEditor` created a severe performance bottleneck. Because the code editor updates its state on every keystroke, the entire `MainLayout` component re-renders constantly. This caused all heavy sibling components (`AgentSidebar`, `FileExplorer`, and `ChatPanel`) to unnecessarily reconcile on every character typed, leading to layout thrashing.
**Action:** Always use `useMemo` to memoize heavy sibling components and `useCallback` for their event handlers when state is lifted to a common parent component that updates frequently (like a code editor's text state). This ensures that only the relevant child component updates while the heavy siblings are skipped during reconciliation.
