## 2024-05-19 - [Performance] Memoize heavy sibling components in React MainLayout
**Learning:** In the frontend React application, lifting state up to a central layout component (like tracking `CodeEditor` keystrokes in `MainLayout` or tracking active file/models) requires heavy sibling components (like `AgentSidebar`, `FileExplorer`, and `ChatPanel`) to be memoized using `React.memo`, and callbacks passed to them memoized using `useCallback`. This prevents severe layout thrashing and unnecessary reconciliation when the central layout's state changes (e.g. typing in the code editor causing the whole layout and all sidebars to re-render).
**Action:** When working on React layout components that hold shared state, proactively apply `React.memo` to child components and use `useCallback` for event handlers passed as props to prevent expensive full-page re-renders on every keystroke.
