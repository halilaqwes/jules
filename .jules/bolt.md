## 2024-05-18 - [Fix React Re-renders on Keystrokes]
**Learning:** In a heavily componentized React layout (like MainLayout combining an Editor, Sidebar, Explorer, and Chat), lifting state up (like the `code` content for the editor) causes the entire layout to re-render on every keystroke. This causes severe layout thrashing and performance degradation because sibling components (like FileExplorer, AgentSidebar) are needlessly re-rendered.
**Action:** When lifting frequently changing state up to a central layout component, always use `React.memo` on the sibling components and `useCallback` for the handler functions passed to them. This guarantees that only the component actually affected by the state change (e.g. CodeEditor) re-renders, protecting the rest of the application's performance.
