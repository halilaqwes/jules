## 2024-06-25 - React Component Re-render Optimization on Keystrokes
**Learning:** In the React frontend, tracking `CodeEditor` keystrokes by lifting the `code` state up to the central `MainLayout` component causes severe layout thrashing and unnecessary reconciliation. Heavy sibling components (`AgentSidebar`, `ChatPanel`, `FileExplorer`) will re-render on every single keystroke because state changes in the parent component re-render all its children by default.
**Action:** When lifting state up to a parent component that contains heavy sibling components, always wrap the sibling components in `React.memo` (or use `useMemo`). Furthermore, any callback functions passed down as props to these memoized components must be wrapped in `useCallback` to maintain a stable reference and allow the child components to correctly skip re-renders.
