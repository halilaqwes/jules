## 2024-05-26 - Prevent severe layout thrashing when lifting code editor state up
**Learning:** In the React frontend architecture, lifting `code` state up to a central layout component (`MainLayout`) causes severe layout thrashing. Because the code state updates on *every single keystroke* in the `CodeEditor`, any unmemoized sibling component in the layout (like `AgentSidebar`, `ChatPanel`, and `FileExplorer`) will re-render unnecessarily on every keystroke, leading to significant input lag and CPU overhead.
**Action:** When centralizing frequent-update state (like code editor input) in a parent layout component, strictly enforce memoization on all heavy sibling components using `React.memo`, and ensure all callbacks passed to them are stabilized using `useCallback` so they don't break memoization checks.
