## 2026-06-27 - [React Performance Improvement: Lifting State Up with Heavy Siblings]
**Learning:** In the frontend React application, lifting state up to a central layout component (like tracking `CodeEditor` keystrokes in `MainLayout`) causes all sibling components to re-render by default. If siblings are complex or heavy (e.g., `AgentSidebar`, `FileExplorer`, `ChatPanel`), this causes severe layout thrashing and unnecessary reconciliation on every keystroke, resulting in a laggy typing experience.
**Action:** When centralizing state that updates frequently (like editor content), ensure heavy sibling components are memoized using `React.memo` or `useMemo`, and pass down stable callbacks using `useCallback`. This isolates the frequent state changes to only the components that need it (the `CodeEditor`).
